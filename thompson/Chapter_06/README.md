# Note about chapter 6

I would strongly recommend reading chapter 7.1-4 before making the exercises from chapter 6. Although the overall idea is to apply available list functions and list comprehensions as much as possible, this is not always desirable or possible. In such cases, recursion over lists is the way to go, which is covered in the first sections of chapter 7. These sections also give more information about pattern matching on lists, which will be useful in the exercises as well.
