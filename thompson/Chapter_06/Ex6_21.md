# Exercise 6.21

Drawing further upon the previous exercise, how would we redefine the function `printPicture` to work with this new column-based representation of `Picture`?

Printing a picture is inherently a row-based operation, as we typically display images line by line from top to bottom. Therefore, to print a picture represented as a list of columns, there is no straightforward way to do this without first converting it back to a row-based format.

To achieve this, we can simply take our implementation of `transpose` from exercise 6.8 and compose it with the existing `printPicture` function. Thus, we get the following definition:

```haskell
printPicture' :: Picture -> IO ()
printPicture' = printPicture . transpose
```
