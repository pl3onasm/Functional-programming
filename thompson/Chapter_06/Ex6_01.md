# Exercise 6.1

What are the most general types of the following functions?

## 6.1.1

```haskell
snd (x, y) = y
```

Tuple types in Haskell can have any types for their components (the components are covariant). The definiton of `snd` takes a tuple and returns its second component, and does not impose any constraints on the types of the components. Therefore, the most general type of `snd` is:

```haskell
snd :: (a, b) -> b
```

## 6.1.2

```haskell
sing x = [x]
```

The function `sing` takes a value and returns a singleton list containing that value. There are no constraints on the type of the input value, so it can be of any type, as long as the output is a list of that same type. Therefore, the most general type of `sing` is:

```haskell
sing :: a -> [a]
```
