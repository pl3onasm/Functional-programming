# Exercise 6.38

We have defined several properties of pictures in the exercises of this chapter (e.g. 6.11-6.14). The question now is: do these properties also hold for images?

If we represent image transformations according to the naive view (see p. 149 and exercise 6.33), then all properties carry over from the picture operations to the image operations. However, if we represent image transformations in accordance with the geometrical view (see p. 150 and exercises 6.34-6.37), then only the property for color inversion still holds, but the other properties do not.

This is because the position of the reference point changes when we apply an image transformation. For example, if we flip an image in a horizontal mirror, then the reference point moves to the opposite side of the image. And if we put two images beside each other, then the position of the reference point of the second image depends on the width of the first image. Since the properties that were formulated for pictures are equalities, this means that in the case of images also the reference points must be equal for the two sides of the equality. As this is not the case for most image operations, the properties fail to hold. A way to fix this would be to rewrite the properties to incorporate the coordinate shifts of the reference points, or to redefine equality of images in a way that accounts for reference point positions.
