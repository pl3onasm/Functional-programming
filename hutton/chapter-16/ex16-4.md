# Exercise 16.4

Given is the following definition:

```haskell
  (++) :: [a] -> [a] -> [a]
  [] ++ ys = ys
  (x : xs) ++ ys = x : (xs ++ ys)
```

The task is to verify the following two properties *p* and *q*:

> p(xs): xs ++ [ ] = xs
>
> q(xs): xs ++ (ys ++ zs) = (xs ++ ys) ++ zs

We will do this by induction on lists. In particular, by induction on the list argument *xs* in *p* and *q*.

---------------------------------

## Property p

### Base case: prove p([])

```text
      {LHS of p([])}
    [] ++ []
  =   {applying ++}
    []
  =   {RHS of p([])}
```

### Inductive case: prove p(xs) => p((x : xs))

```text
  __________________________
    Induction hypothesis:

      p(xs): xs ++ [] = xs
  __________________________

      {LHS of p((x : xs))}
    (x : xs) ++ []
  =   {applying ++}
    x : (xs ++ [])
  =   {induction hypothesis}
    x : xs
      {RHS of p((x : xs))}
```

---------------------------------

## Property q

### Base case: prove q([])

```text
      {LHS of q([])}
    [] ++ (ys ++ zs)
  =   {applying ++}
    ys ++ zs
  =   {unapplying ++}
    ([] ++ ys) ++ zs
      {RHS of q([])}
```

### Inductive case: prove q(xs) => q((x : xs))

```text
  _______________________________
    Induction hypothesis:

      q(xs): xs ++ (ys ++ zs) 
             = (xs ++ ys) ++ zs
  _______________________________

      {LHS of q((x : xs))}
    (x : xs) ++ (ys ++ zs)
  =   {applying ++}
    x : (xs ++ (ys ++ zs))
  =   {induction hypothesis}
    x : ((xs ++ ys) ++ zs)
  =   {unapplying ++}
    (x : (xs ++ ys)) ++ zs
  =   {unapplying ++}
    ((x : xs) ++ ys) ++ zs
      {RHS of q((x : xs))}
```

---------------------------------

Hence, both properties *p* and *q* hold for all lists.

□
