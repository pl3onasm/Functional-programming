# Exercise 16.4

Given is the following definition:

```haskell
  (++) :: [a] -> [a] -> [a]
  [] ++ ys = ys
  (x : xs) ++ ys = x : (xs ++ ys)
```

The task is to verify the following two properties *p* and *q*:

> p(xs): xs ++ [] = xs
>
> q(xs): xs ++ (ys ++ zs) = (xs ++ ys) ++ zs

We will do this by induction on lists. In particular, by induction on the list argument *xs* in *p* and *q*.

---------------------------------

## Property p

### Base case: p([])

```text
      {LHS of p([])}
    [] ++ []
  =   {applying ++}
    []
```

### Inductive case: p(x : xs)

```text
  __________________________
    Induction hypothesis:

      p(xs): xs ++ [] = xs
  __________________________

      {LHS of p(x : xs)}
    (x : xs) ++ []
  =   {applying ++}
    x : (xs ++ [])
  =   {induction hypothesis}
    x : xs
```

---------------------------------

## Property q

### Base case: q([])

```text
      {LHS of q([])}
    [] ++ (ys ++ zs)
  =   {applying ++}
    ys ++ zs
  =   {unapplying ++}
    ([] ++ ys) ++ zs
```

### Inductive case: q(x : xs)

```text
  _______________________________
    Induction hypothesis:

      q(xs): xs ++ (ys ++ zs) 
             = (xs ++ ys) ++ zs
  _______________________________

      {LHS of q(x : xs)}
    (x : xs) ++ (ys ++ zs)
  =   {applying ++}
    x : (xs ++ (ys ++ zs))
  =   {induction hypothesis}
    x : ((xs ++ ys) ++ zs)
  =   {unapplying ++}
    (x : (xs ++ ys)) ++ zs
  =   {unapplying ++}
    ((x : xs) ++ ys) ++ zs
```

---------------------------------

Hence, both properties *p* and *q* hold for all lists.

□
