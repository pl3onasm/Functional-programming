# Exercise 16.2

Given is the data type

```haskell
  data Nat = Zero | Succ Nat
```

and the definition for addition:

```haskell
  add :: Nat -> Nat -> Nat
  add Zero m = m
  add (Succ n) m = Succ (add n m)
```

We are also given the following properties:

- property (1): `add n (Succ m) = Succ (add n m)`
- property (2): `add n Zero = n`

We need to prove the following property *p* holds for all *n* ∈ Nat:

> p(n): add n m = add m n

This will be done by induction on *n*.

--------------------------------

## Base case: prove p(Zero)

```text
      {LHS of p(Zero)}
    add Zero m
  =   {applying add}
    m
  =   {using property (2) in reverse}
    add m Zero
```

## Inductive case: prove p(n) => p(Succ n)

```text
  ______________________________
    Induction hypothesis:

      p(n): add n m = add m n
  ______________________________

      {LHS of p(Succ n)}
    add (Succ n) m
  =   {applying add}
    Succ (add n m)
  =   {induction hypothesis}
    Succ (add m n)
  =   {using property (1) in reverse}
    add m (Succ n)
```

--------------------------------

Hence, the property *p* holds for all *n* ∈ Nat.

□
