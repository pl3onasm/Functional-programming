# Exercise 16.1

Given is the data type

```haskell
  data Nat = Zero | Succ Nat
```

and the definition for addition:

```haskell
  add :: Nat -> Nat -> Nat
  add Zero m = m
  add (Succ n) m = Succ (add n m)
```

We need to prove the following property *p* holds for all *n* ∈ Nat:

> p(n): add n (Succ m) = Succ (add n m)

We will do this by induction on *n*.

--------------------------------

## Base case: prove p(Zero)

```text
      {LHS of p(Zero)}
    add Zero (Succ m)
  =   {applying add}
    Succ m
  =   (unapplying add)  
    Succ (add Zero m)
```

## Inductive case: prove p(n) => p(Succ n)

```text
  ___________________________________________
    Induction hypothesis:

      p(n): add n (Succ m) = Succ (add n m)
  ___________________________________________

      {LHS of p(Succ n)}
    add (Succ n) (Succ m)
  =   {applying add}
    Succ (add n (Succ m))
  =   {induction hypothesis}
    Succ (Succ (add n m))
  =   {unapplying add}
    Succ (add (Succ n) m)
```

--------------------------------

Hence, the property *p* holds for all *n* ∈ Nat.
