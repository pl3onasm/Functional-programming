# Exercise 16.10

The task is to verify the monad laws for the list type. The instance of the Monad type class for lists is given as follows:

```haskell
  instance Monad [] where
    -- return :: a -> [a]
    return x = [x]

    -- (>>=) :: [a] -> (a -> [b]) -> [b]
    xs >>= f = [y | x <- xs, y <- f x]
```

  The monad laws are:

> (1) return x >>= f = f x
>
> (2) mx >>= return = mx
>
> (3) (mx >>= f) >>= g = mx >>= (\x -> (f x >>= g))

We will verify each law in turn.

--------------------------------

## Law 1: return x >>= f = f x

```text
      {LHS of law 1}
    return x >>= f
  =   {definition of return}
    [x] >>= f
  =   {definition of >>=}
    [y | x' <- [x], y <- f x']
  =   {list comprehension over singleton list}
    [y | y <- f x]
  =   {removing dummy variable}
    f x
      {RHS of law 1}

  ∴ LHS = RHS
```

--------------------------------
## Law 2: mx >>= return = mx

```text
      {LHS of law 2}
    mx >>= return
  =   {definition of >>=}
    [y | x <- mx, y <- return x]
  =   {definition of return}
    [y | x <- mx, y <- [x]]
  =   {list comprehension over singleton list}
    [x | x <- mx]
  =   {removing dummy variable}
    mx
      {RHS of law 2}

  ∴ LHS = RHS
```

--------------------------------

## Law 3: (mx >>= f) >>= g = mx >>= (\x -> (f x >>= g))

```text
      {LHS of law 3}
    (mx >>= f) >>= g
  =   {definition of >>=}
    [z | x <- (mx >>= f), z <- g x]
  =   {definition of >>= inside the generator}
    [z | x <- [y | x <- mx, y <- f x], z <- g x]
  =   {flattening nested list comprehension}
    [z | x <- mx, y <- f x, z <- g y]

      {RHS of law 3}
    mx >>= (\x -> f x >>= g)
  =   {definition of >>=}
    [z | x <- mx, z <- (f x >>= g)]
  =   {definition of >>= inside the generator}
    [z | x <- mx, z <- [z' | y <- f x, z' <- g y]]
  =   {flattening nested list comprehension}
    [z | x <- mx, y <- f x, z <- g y]

  ∴ LHS = RHS
```

Therefore, since all three monad laws hold for the list type and the instance of the Monad type class provided above, we conclude that lists form a lawful monad.
