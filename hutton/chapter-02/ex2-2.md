# Exercise 2.2

Task: add parentheses to the following numeric expressions so that the order of evaluation is made explicit, without changing their meaning.

> 2^3*4
>
> 2\*3+4\*5
>
> 2+3*4^5

In Haskell, operator precedence and associativity follow standard mathematical conventions:

    - (^) has the highest precedence (right-associative)
    - (*) and (/) come next (left-associative)
    - (+) and (-) have the lowest precedence (left-associative)

Hence, the parenthesized versions of the expressions are:

```haskell
  (2 ^ 3) * 4
  (2 * 3) + (4 * 5)
  2 + (3 * (4 ^ 5))
```

To confirm that these expressions are equivalent to the originals, we can check them in GHCi:

```text
  ghci> 2^3*4 == (2^3) * 4
  True
  ghci> 2*3+4*5 == (2 * 3) + (4 * 5)
  True
  ghci> 2+3*4^5 == 2 + (3 * (4 ^ 5))
  True
```

The outputs confirm that the parentheses preserve the meaning and merely clarify the evaluation order.
