{- 
 a. We modify the original grammar by replacing the 
    right-associative + operator with a left-associative 
    - operator. The revised grammar is:

        expr   ::= expr - term | term
        term   ::= factor ( * term | ε ) 
        factor ::= ( expr ) | nat
        nat    ::= 0 | 1 | 2 | ...

    Only the first line has changed. The introduction of 
    left recursion means that subtraction is interpreted 
    as left-associative, enforcing a structure like 
    (((e1 - e2) - e3) - ... - en).

 b. Implementing this grammar directly only requires 
    changing the parser for expr to use the new 
    left-associative subtraction operator. The other 
    parsers (term, factor, nat) remain unchanged.

    A direct (but problematic) parser for expr is:

        expr :: Parser Int
        expr = 
          do e <- expr          -- left-recursive call
             symbol "-"
             t <- term
             return (e - t)
            <|> term

 c. This parser is left-recursive. Combined with our 
    top-down recursive-descent parser, this causes 
    non-termination because the parser repeatedly calls 
    itself without consuming any input: to parse expr, 
    it calls expr again, and so on, with no base case 
    ever reached.

 d. To fix this, we eliminate the left recursion while 
    preserving the left-associative semantics of 
    subtraction. We parse an initial term, followed by 
    zero or more (- term) segments, and combine the 
    results using foldl:

        expr :: Parser Int
        expr = do
          t  <- term
          ts <- many (do symbol "-"
                         term)
          return (foldl (-) t ts)

    Here, many (do symbol "-"; term) collects zero or 
    more terms that follow a "-" symbol, returning a 
    list ts. The initial term is parsed as t, and we 
    use foldl (-) t ts to ensure left associativity.

    A similar fix can be applied to the term parser
    to handle left-associative division. See exersise
    13.9 for an implementation of both left-associative
    subtraction and division.

 e. An alternative way to implement left-associative 
    parsing is to restructure the grammar using 
    auxiliary non-terminals. These helper rules flatten 
    the recursion and enable left-associative parsing 
    without introducing left recursion. The revised 
    grammar becomes:

        expr   ::= term expr'
        expr'  ::= "+" term expr' 
                 | "-" term expr'
                 | ε
        term   ::= factor term'
        term'  ::= "*" factor term' 
                 | "/" factor term'
                 | ε
        factor ::= "(" expr ")" | nat

    This solution does in fact the same as the previous
    one, but is more complex as it introduces additional
    non-terminals (expr' and term') to handle the to 
    handle the left-associative structure without intro-
    ducing left recursion. Using foldl is a more concise 
    and idiomatic way to achieve the same result in 
    Haskell.

-}
