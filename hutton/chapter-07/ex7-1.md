# Exercise 7.1

We are given the following list comprehension:
  
```haskell
  [f x | x <- xs, p x]
```
  
This expression builds a list by:

  1. First taking each element x from the list xs: this is the generator part
  2. Then filtering out elements for which the predicate p x is False: this is the guard part
  3. Finally, applying the function f to the remaining elements: this is the mapping part

In other words, it maps f over all elements of the list xs that satisfy the predicate p.

The same functionality can thus also be accomplished by:

```haskell
  map f (filter p xs)
```

Thus, it is clear that list comprehensions in Haskell are, in fact, syntactic sugar for combinations of map and filter.

For example, if we have:

  f = (*2)
  p = even
  xs = [1..5]

Then the list comprehension becomes:

    [f x | x <- xs, p x]

  = [(*2) x | x <- [1..5], even x]

  = [(*2) x | x <- [2,4]]

  = [4,8]

This is equivalent to:

```haskell
  map (*2) (filter even [1..5])
```
