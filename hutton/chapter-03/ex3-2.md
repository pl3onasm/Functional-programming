# Exercise 3.2

We are tasked with writing down definitions that have the following types.

> bools :: [Bool]
>
> nums :: [[Int]]
>
> add :: Int -> Int -> Int -> Int
>
> copy :: a -> (a,a)
>
> apply :: (a -> b) -> a -> b

## Solution

(1) `bools` is a list of Boolean values. A definition could be:

```haskell
bools :: [Bool]
bools = [True, False, True]
```

(2) `nums` is a list of lists of integers. A definition could be:

```haskell
nums :: [[Int]]
nums = [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
```

(3) `add` is a function that takes three integers and returns an integer. Given the name of the function, it likely adds the three integers together. A definition could be:

```haskell
add :: Int -> Int -> Int -> Int
add x y z = x + y + z
```

(4) `copy` is a function that takes a value of any type and returns a tuple containing two copies of that value. A definition could be:

```haskell
copy :: a -> (a, a)
copy x = (x, x)
```

(5) `apply` is a function that takes a function and an argument, applies the function to the argument, and returns the result. A definition could be:

```haskell
apply :: (a -> b) -> a -> b
apply f x = f x
```

or using the `($)` operator:

```haskell
apply :: (a -> b) -> a -> b
apply = ($) 
```
