# Exercise 3.1

The task is to determine the types of the following Haskell expressions:

> (1): ['a','b','c']
>
> (2): ('a','b','c')
>
> (3): [(False,'0'),(True,'1')]
>
> (4): ([False,True],['0','1'])
>
> (5): [tail, init, reverse]

## Solution

(1) This is a list of characters. As String is an alias for [Char] in Haskell, we can use both types interchangeably. Thus, the type is:

```haskell
['a', 'b', 'c'] :: [Char]
```

(2) This is a tuple containing three characters. The type is:

```haskell
('a', 'b', 'c') :: (Char, Char, Char)
```

(3) This is a list of tuples, where each tuple contains a Bool and a Char. The type is:

```haskell
[(False, '0'), (True, '1')] :: [(Bool, Char)]
```

(4) This is a tuple containing a list of Booleans and a list of characters. The type is:

```haskell
([False, True], ['0', '1']) :: ([Bool], [Char])
```

(5) This is a list of functions. The functions `tail`, `init`, and `reverse` all have the same type signature, which is a function that takes a list of type `a` and returns a list of the same type. Therefore, the type is:

```haskell
[tail, init, reverse] :: [[a] -> [a]]
```
