# Exercise 3.3

Given the following functions, write down their types.

> second xs = head (tail xs)
>
> swap (x,y) = (y,x)
>
> pair x y = (x,y)
>
> double x = x * 2
>
> palindrome xs = xs == reverse xs
>
> twice f x = f (f x)

## Solution

(1) `second` takes a list and returns the second element of that list. Its type is:

```haskell
second :: [a] -> a
```

(2) `swap` takes a tuple of two elements and returns a tuple with the elements swapped. Its type is:

```haskell
swap :: (a, b) -> (b, a)
```

(3) `pair` takes two values and returns a tuple containing those two values. Its type is:

```haskell
pair :: a -> b -> (a, b)
```

(4) `double` takes a number and returns its double. Its type is:

```haskell
double :: Num a => a -> a
```

The constraint `Num a` indicates that `x` must be a numeric type, since `*` is an operation defined for the class `Num`.

(5) `palindrome` takes a list and checks if it is equal to its reverse, returning a Boolean value. Its type is:

```haskell
palindrome :: Eq a => [a] -> Bool
```

The constraint `Eq a` indicates that the elements of the list must be of a class that is an instance of `Eq`, meaning that the equality operator `(==)` can be used on them.

(6) `twice` takes a function and an argument, applies the function twice to the argument, and returns the result. Its type is:

```haskell
twice :: (a -> a) -> a -> a
```

The first input to `twice` is a function that takes an argument of type `a` and necessarily returns a value of that same type `a`, since the output of the first application is used as the input for the second application. We say that the function is endomorphic, meaning it maps a type to itself.
