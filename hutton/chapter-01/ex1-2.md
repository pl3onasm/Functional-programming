# Exercise 1.2

Given is the following definition of *sum*:

```haskell
  sum :: [Int] -> Int
  sum []       = 0
  sum (n : ns) = n + sum ns
```

We are asked to show for any number *x* that

> sum [x] = x

To show this, we will simply apply the definition of *sum* to the singleton list containing *x*:

```text
  sum [x]
=   {[x] is syntactic sugar for (x : [])}
  sum (x : [])
=   {applying the recursive case of sum}
  x + sum []
=   {applying the base case of sum}
  x + 0
=   {applying +}
  x
```

Thus, we have shown that for any number *x*, the property `sum [x] = x` holds true. This demonstrates the correctness of the *sum* function for a singleton list.
