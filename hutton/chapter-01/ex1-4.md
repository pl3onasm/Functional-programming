# Exercise 1.4

Given is the following definition of *qsort*:

```haskell
  qsort :: Ord a => [a] -> [a]
  qsort [] = []
  qsort (x : xs) = qsort smaller ++ [x] ++ qsort larger
    where
      smaller = [a | a <- xs, a <= x]
      larger  = [b | b <- xs, b > x]
```

The question asked is how we can modify this definition such that it produces a reverse sorted version of a list.

This can be done by swapping the recursive calls to *qsort* for the *smaller* and *larger* lists. This way, we modify the order of the partitioning such that the larger elements are processed first, followed by the pivot element *x*, and then the smaller elements. The modified definition then is:

```haskell
  qsort' :: Ord a => [a] -> [a]
  qsort' [] = []
  qsort' (x : xs) = qsort' larger ++ [x] ++ qsort' smaller
    where
      smaller = [a | a <- xs, a <= x]
      larger  = [b | b <- xs, b > x]
```

To verify that this modified version indeed produces a reverse sorted list, we can evaluate the expression `qsort' [3, 1, 4, 2]` step by step:

```text
    qsort' [3, 1, 4, 2]
  =   {applying the recursive case}
    qsort' [4] ++ [3] ++ qsort' [2,1]
  =   {applying the recursive case}
    (qsort' [] ++ [4] ++ qsort' []) ++ [3] ++ qsort' [2,1]
  =   {applying the base case}
    ([] ++ [4] ++ []) ++ [3] ++ qsort' [2,1]
  =   {applying ++}
    [4] ++ [3] ++ qsort' [2,1]
  =   {applying the recursive case}
    [4] ++ [3] ++ (qsort' [] ++ [2] ++ qsort' [1])
  =   {applying the base case and ++}
    [4] ++ [3] ++ ([2] ++ qsort' [1])
  =   {applying the recursive case}
    [4] ++ [3] ++ ([2] ++ (qsort' [] ++ [1] ++ qsort' []))
  =   {applying the base case}
    [4] ++ [3] ++ ([2] ++ ([1] ++ []))
  =   {applying ++}
    [4] ++ [3] ++ [2, 1]
  =   {applying ++}
    [4, 3, 2, 1]
```

Hence, qsort' [3, 1, 4, 2] = [4, 3, 2, 1], as expected for reverse order.
