# Exercise 1.3

We are tasked with implementing a function *product* that computes the product of a list of numbers. The function should take a list of integers and return their product.

We are also asked to show that

```haskell
product [2, 3, 4] == 24
```

using the given definition of the *product* function.

--------------------------------

A function for computing the product of a list of numbers can easily be defined on the same lines as the *sum* function. All we need to do is replace the addition operator with the multiplication operator, and replace the identity element for addition (0) returned by the base case with the identity element for multiplication (1).

Hence, we define the *product* function as follows:

```haskell
  product :: [Int] -> Int
  product []       = 1
  product (n : ns) = n * product ns
```

To verify that this function works correctly, we can evaluate the expression `product [2, 3, 4]` step by step as requested.

```text
    product [2, 3, 4]
  =   {applying the recursive case}
    2 * product [3, 4]         
  =   {applying the recursive case}
    2 * (3 * product [4])       
  =   {applying the recursive case}
    2 * (3 * (4 * product []))   
  =   {applying the base case}
    2 * (3 * (4 * 1))            
  =   {performing the inner multiplication}
    2 * (3 * 4)
  =   {performing the inner multiplication}
    2 * 12
  =   {performing the multiplication}
    24
```
